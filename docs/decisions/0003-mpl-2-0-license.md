# 0003 MPL-2.0 license

## Context

flust is a privacy app: users need to be able to verify that it does what it claims, and that modified versions stay verifiable.

## Decision

The source code is released under the Mozilla Public License 2.0 (`LICENSE`).

## Consequences

- Copyleft applies per file: modified MPL files must be published under the MPL when distributed.
- MPL code can be combined with files under other licenses, including proprietary ones, which keeps app store distribution and third-party dependencies simple.
- Contributions are accepted under the same license.
